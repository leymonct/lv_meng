# 绿梦小助手（Lumin Assistant）

一款针对游戏《绿梦（Lumin）》的自动化操作助手，支持**操作录制与回放**、**跨地图自动传送**、**循环刷怪**。

无需修改游戏本体，通过图像匹配 + 键鼠模拟驱动。

## ✨ 功能特性

- **图形界面**：左侧三栏导航（运行 / 脚本管理 / 运行日志），一键启动/停止、实时查看运行日志
- **操作录制**：录制键鼠操作（带精确时间轴），录完自动生成脚本，按原节奏回放
- **循环刷怪**：录制一次，自动循环执行；配置休息点图后支持「刷怪 + 就近传送」完整循环
- **跨地图传送**：内置五大地区传送逻辑，图像匹配定位，适配窗口位置变化
- **脚本管理**：自定义命名、设置循环次数、删除脚本、配置休息点与传送点
- **可靠性守护**：传送失败自动重试 + 连续失败熔断；掉线/卡读条异常自动暂停
- **启动体检**：启动前检查游戏窗口、模板图、传送点配置，缺失即阻断
- **运行统计**：实时显示已跑轮数、平均耗时、传送成功率

## 🚀 快速开始

### 环境要求

- Windows 10/11（64 位）
- 屏幕分辨率 **1920×1080**（图像识别模板图按此分辨率录制，其他分辨率可能识别不准）

### 安装

下载 `Lumin-Setup.exe`，双击走标准安装向导（默认安装到用户目录），装完桌面和开始菜单会有快捷方式，之后双击即可。

> 程序会自动请求管理员权限（模拟按键需要），首次启动会弹 UAC 确认，点「是」即可。

## 📖 使用说明

### 1. 录制一个刷怪脚本

1. 启动程序，在左侧导航切到「脚本管理」页，点击「启动录制」
2. 切回游戏，按 `F7` 开始录制，操作一轮完整的刷怪流程
3. 再按 `F7` 停止录制，脚本自动保存并加入列表（录制器自动退出）

### 2. 运行脚本

1. 切到「运行」页，在下拉框选择要运行的脚本
2. 按需设置「循环次数」（0 表示无限循环）
3. 点击「启动」，程序会自动切换到游戏窗口并开始运行
4. 运行中按 `F8` 开始 / 暂停循环，按 `Esc` 退出

### 3. 配置就近传送（可选）

- 在「脚本管理」页选中脚本后，点击「选择休息点图」，上传一张游戏里的休息点图标截图
- 配置后，脚本会在每轮刷怪后自动传送回休息点，实现完整循环

### 4. 配置跨地图传送点（可选）

- 在「脚本管理」页点击「配置传送点」，选择所在地区、填写传送点名称、上传传送点图标截图
- 在「运行」页勾选「启动时自动传送到目标地图」，运行前会先传送到目标地图再开始刷怪

## ⚠️ 注意事项

- **必须管理员权限运行**，否则游戏窗口收不到模拟按键
- 游戏窗口需保持在前台，程序会自动切换焦点
- 传送点/休息点图标需截图清晰、背景干净，否则图像匹配可能失败
- **屏幕分辨率需为 1920×1080**：图像识别模板图按此分辨率录制，换显示器/改缩放会识别不准
- 本工具仅供学习交流，请勿用于破坏游戏公平性或违反游戏条款的用途
